# 人情往来

> 记礼金、看关系、过好每一个该到的日子。

一个运行在 **飞牛 fnOS** 上的第三方应用：把亲友关系、礼金台账、生日忌日、人情往来全部整理到一处，支持多设备共享同一份账本，并可通过飞牛统一网关在外网访问。

## 功能

- **关系图谱**：以自己为中心，按「至亲 / 亲友 / 朋友」分层展示亲友关系；支持缩放（简略 / 标准 / 详细）与圈层筛选；夫妻卡片成对显示，点击卡片直达档案。
- **礼金台账**：记录每一笔收送，按方向、时间、人员筛选统计；可一键隐藏金额后分享。
- **人情日历**：生日、忌日自动生成日程，可自定义纪念日等事项，支持每年重复与倒计时提醒。
- **分享中心**：按类型导出礼金台账 / 人际关系 / 人员信息 / 日历，可复制文案、保存图片、生成只读分享链接。
- **人员档案**：记录手机号、地址、生日、标签、头像（支持上传照片）。
- **多设备同步**：数据保存在 NAS 本地目录，手机 / 电脑 / 家人打开同一地址看到同一份账本。
- **数据路径可配置**：可将数据目录切换到自己的共享文件夹。

## 目录结构

```
.
├── index.html                     # 网页应用入口（本地浏览器直接打开也可用）
├── css/                           # 样式
├── js/                            # 前端逻辑（app / data / graph / share）
├── fpk/feiniu-renqing/            # 飞牛 FPK 工程源码
│   ├── manifest                   # 应用清单（名称、版本、端口等）
│   ├── cmd/main                   # 生命周期脚本（start/stop/status）
│   ├── config/                    # 权限与资源配置
│   ├── app/server.py              # 后端服务：静态托管 + 数据/头像 API + 网关
│   ├── app/ui/                    # 桌面入口配置与图标
│   └── app/web/                   # 前端文件（由根目录同步而来）
├── 人情往来_1.1.0.fpk            # 安装包（可直接手动安装）
└── 人情往来_1.0.0.fpk            # 旧版安装包
```

## 安装

1. 将 `人情往来_1.1.0.fpk` 传到飞牛 NAS 任意目录。
2. 打开 **应用中心 → 右上角「手动安装」**，选择该文件。
3. 安装完成后，桌面出现「人情往来」图标，点击即可打开（内嵌窗口，非外部网页）。

应用通过飞牛**统一网关**提供访问：局域网内与外网（FN Connect）走同一入口，由系统负责鉴权，无需单独映射端口。

## 数据存储

- 默认保存在应用 `var` 目录下的 `data/state.json`，头像保存在 `data/avatars/`。
- 可在应用内 **我的 → 数据保存路径** 查看或切换到其他目录。
- 建议定期在 **我的 → 导出备份** 下载 JSON 备份。

## 从源码重新打包

需要飞牛官方打包工具 `fnpack`（可在飞牛开发者中心下载）。在 `fpk/feiniu-renqing/` 目录执行：

```bash
fnpack build
```

生成的 `feiniu-renqing.fpk` 即为安装包。前端改动后，请先同步到 `fpk/feiniu-renqing/app/web/`。

## 说明

- 应用名称「人情往来」；内部包名 `feiniu-renqing` 用于应用中心识别，请勿随意更改。
- 首次打开会载入示例数据，可在 **我的 → 清空并重新开始** 清除。
- 本项目为本地优先应用，数据不上传第三方服务器。
