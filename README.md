# 人情往来

> 记礼金、看关系、写故事，过好每一个该到的日子。

一个运行在 **飞牛 fnOS** 上的第三方应用：把亲友关系、礼金台账、生日忌日、故事回忆、人情往来全部整理到一处，支持账户登录、多设备共享同一份账本，并可通过飞牛统一网关在外网访问。

## 功能

- **账户登录**：进入应用需要先登录。首次使用默认管理员账号 `admin / admin123`（登录后请尽快修改密码）。支持**自行注册**，也支持**管理员在设置里新增账户**、重置密码、删除账户、分配角色（管理员/成员），并可开关自助注册。
- **我的（首页）**：默认打开，展示个人资料、收支结余、圈层分布、近期事项、最近往来，并可一键写故事、添加成员、记一笔。
- **故事**：以时间线记录与某些人、某群人经历的事情回忆，也可记下有趣的日子；支持关联多位成员、心情、日期、标签，按成员筛选。
- **五套主题**：暖白（默认）、墨夜、青竹、藏蓝、雅紫，一键切换，自动记住每个账户的选择。
- **设置中心**：把「账户管理、主题外观、数据设置」统一收纳到「设置」栏目。
- **关系图谱**：以自己为中心，按「至亲 / 亲友 / 朋友」分层展示亲友关系；支持缩放（简略 / 标准 / 详细）与圈层筛选；夫妻卡片成对显示，点击卡片直达档案。
- **礼金台账**：记录每一笔收送，按方向、时间、人员筛选统计。
- **人情日历**：生日、忌日自动生成日程，可自定义纪念日等事项，支持每年重复与倒计时提醒。
- **人员档案**：记录手机号、地址、生日、标签、头像（支持上传照片）。
- **分享中心**：左下角「分享中心」保留，可分享台账、关系、人员信息（支持隐藏金额、附带联系方式）；页面右上角的分享按钮已移除。
- **多设备同步**：数据保存在 NAS 本地目录，手机 / 电脑 / 家人打开同一地址看到同一份账本。
- **数据路径可配置**：可将数据目录切换到自己的共享文件夹。

## 安装

1. 将 `人情往来_1.2.8.fpk` 传到飞牛 NAS 任意目录。
2. 打开 **应用中心 → 右上角「手动安装」**，选择该文件。
3. 安装完成后，桌面出现「人情往来」图标，点击即可打开（内嵌窗口，非外部网页）。
4. 首次打开用 `admin / admin123` 登录，随后到 **设置 → 账户 → 修改密码** 更改默认密码。

> 若从旧版覆盖升级后桌面图标仍是默认样式，请到应用中心**卸载后重新安装**本包（飞牛升级安装不会刷新第三方应用图标缓存）。

应用通过飞牛**统一网关**提供访问：局域网内与外网（FN Connect）走同一入口，由系统负责鉴权，无需单独映射端口。

## 账户说明

- 默认管理员：`admin / admin123`。账户数据保存在应用 `var/users.json`，令牌保存在 `var/tokens.json`，与账本数据目录相互独立，切换数据路径不会影响账户。
- 自助注册默认开启，成员可以正常使用账本、修改自己的密码与主题；管理员额外拥有账户管理与数据设置权限。
- 关闭自助注册后，只能由管理员在 **设置 → 账户管理 → 新增账户** 添加成员。

## 数据存储

- 默认保存在应用 `var` 目录下的 `data/state.json`，头像保存在 `data/avatars/`。
- 可在应用内 **设置 → 数据 → 数据保存路径** 查看或切换到其他目录。
- 建议定期在 **设置 → 数据 → 导出备份** 下载 JSON 备份。

## 从源码重新打包

需要飞牛官方打包工具 `fnpack`。在 `fpk/feiniu-renqing/` 目录执行：

```bash
fnpack build
```

生成的 `feiniu-renqing.fpk` 即为安装包。前端改动后，请先同步到 `fpk/feiniu-renqing/app/web/`。打包前请确认 `app/` 下没有残留的 `app.sock` 或 `__pycache__`。

## 说明

- 应用名称「人情往来」；内部包名 `feiniu-renqing` 用于应用中心识别，请勿随意更改。
- 首次打开会载入示例数据，可在 **设置 → 数据 → 清空并重新开始** 清除。
- 本项目为本地优先应用，数据不上传第三方服务器。
